# MaliPhone

MaliPhone 是一款以 AI 角色互動為核心的手機模擬器。

玩家可以建立或匯入自己的角色，透過聊天、社群、角色手機、錢包及各種生活功能與角色互動，逐步累積彼此的關係、故事狀態與長期記憶。

目前版本：`1.2.17`

## 主要特色

- AI 角色單人聊天與群組聊天
- 線上聊天與現實聊天模式
- 角色卡建立、匯入、編輯與匯出
- 多聊天室、回應版本與劇情分支
- 此刻、長期記憶與世界書
- 角色社群、手機、錢包與生活互動
- 聊天截圖與自訂關鍵字遮蔽
- 完整備份、私人雲端備份與跨裝置文字同步
- 支援多種 AI 供應商與自訂 API
- 繁體中文、簡體中文、英文、日文與韓文介面

## 聊天與劇情

### 單人聊天

每位角色都有自己的聊天室，可獨立保存訊息、設定、記憶與劇情進度。

聊天室支援：

- 線上聊天與現實聊天
- 文字、圖片與模擬語音訊息
- 編輯、刪除及重新生成訊息
- 同一則角色回應保存多個版本
- 從目前進度或指定回應建立劇情分支
- 自訂聊天室背景
- 角色主動傳送訊息
- 顯示或隱藏 AI 回覆中的思考內容
- 自訂現實聊天輸出長度

### 手動生成回應

玩家可以選擇不讓角色在每則訊息後立即回覆。

開啟後，可以先連續傳送多個訊息氣泡，再按下「生成回應」，讓角色一次閱讀並回覆完整內容。

### 群組聊天

- 建立及編輯群組
- 選擇多位角色加入群組
- 設定群組名稱與背景
- 支援多角色依序回覆
- 群聊與單聊分別保存自己的對話進度

### 此刻

「此刻」用來記錄目前劇情需要延續的狀態，包括：

- 玩家與角色目前的關係
- 所在地點
- 角色情緒
- 正在進行的事情
- 尚未解決的伏筆
- 玩家自訂備註

每個聊天室與劇情分支都有自己的「此刻」，AI 會依照目前分支的狀態延續故事。

### 劇情分支與時光抽屜

- 從目前對話建立新的故事分支
- 從不同回應版本延伸不同路線
- 在多條劇情路線之間切換
- 將暫時不使用的對話收進「時光抽屜」
- 隨時閱讀或恢復封存的對話

收進時光抽屜的內容不會繼續產生互動或更新角色狀態。

### 劇情快捷抽屜

每個聊天室與分支都能設定自己的常用劇情指令。

玩家可以從輸入框旁快速選取內容，不需要重複輸入相同的敘事要求。

## 角色與玩家資料

### 角色管理

- 手動建立角色
- 匯入角色卡
- 編輯角色名稱、描述、個性及提示詞
- 設定角色頭像與聊天室資料
- 匯出角色卡
- 刪除角色與聊天室
- 管理角色聯絡人資料

### 玩家人格

玩家可以建立不同的人格資料，包括名稱、描述、頭像，以及角色對玩家的稱呼。

切換人格時，會同步切換對應的：

- 聊天內容
- AI 記憶與角色狀態
- 角色手機資料
- 角色錢包
- 社群互動
- 情侶空間資料

部分遊戲進度與共用資料不會跟隨人格切換。

## 記憶與世界書

### 長期記憶

角色可以根據聊天內容建立長期記憶，讓後續互動延續重要事件與關係變化。

玩家可以：

- 查看聊天室目前的長期記憶
- 編輯或刪除記憶
- 將多條記憶壓縮成摘要
- 將暫時不需要的記憶移入「塵封書庫」
- 從塵封書庫搜尋並恢復原始記憶

移入塵封書庫的內容仍會保留，但不會再送入 AI 上下文。

### 世界書

世界書用來保存可重複使用的背景設定，例如世界觀、地點、組織、能力或事件規則。

支援：

- 建立與編輯世界書
- 匯入與匯出世界書
- 建立多個世界書條目
- 為不同聊天室選擇要使用的世界書
- 個別控制書籍與條目的啟用狀態
- AUTO 關鍵字觸發
- PIN 常駐內容

## 社群與角色生活

### 社群

角色可以在模擬社群中發表貼文與留言。

支援：

- 玩家與角色發表貼文
- 角色回覆與留言互動
- 角色自動發文
- 指定允許自動發文的角色
- 收藏與管理貼文
- 角色根據近期互動分享近況

### 角色手機

玩家可以查看角色的模擬手機內容，包括：

- 聯絡人
- 通話紀錄
- 訊息
- 手機內的生活資料

顯示的內容會依角色資料與互動狀態產生。

### 錢包

- 玩家錢包與角色錢包
- 收入與支出紀錄
- 自訂收支分類
- 依角色篩選紀錄
- 每月收支統計
- 週別圖表
- 月結回顧
- 角色間轉帳與互動紀錄

### 情侶空間

玩家可以和角色建立獨立的情侶互動空間，保存對應人格與角色之間的關係內容。

## 聊天截圖

聊天室可以將指定範圍的對話匯出為圖片。

支援：

- 選擇要截取的訊息
- 套用目前聊天室主題
- 隱藏角色名稱
- 隱藏玩家名稱
- 輸入自訂關鍵字進行遮蔽
- 使用「ＯＯ」取代不想公開的內容

遮蔽只會套用在輸出的截圖，不會修改原始聊天紀錄。

## AI 與 API 設定

玩家可以選擇使用自己的 API，或使用目前開放的測試模型服務。

### 支援的 API 來源

- OpenAI
- Claude
- Gemini API
- Google Vertex AI
- DeepSeek
- Grok
- OpenRouter
- NVIDIA NIM
- Ollama
- NovelAI
- OpenAI 相容的本機模型
- 自訂 Base URL 與模型

不同供應商支援的模型、圖片理解、上下文長度及輸出效果可能不同。

### 圖片理解

使用支援圖片輸入的模型時，AI 可以讀取玩家在聊天中傳送的圖片。

歷史圖片可以使用文字摘要保留相關內容，減少每次對話重複傳送原始圖片。

目前沒有內建 AI 圖片生成功能。

### API Key

玩家自行輸入的 API Key 只保存在目前裝置，不會上傳至雲端文字同步，也不會分享給其他玩家。

## 備份與資料同步

### 本機完整備份

可以匯出及還原 MaliPhone 的完整資料，包括支援的圖片與媒體內容。

### 個別匯入與匯出

- 角色卡
- 聊天室
- 世界書
- 全域資料

匯入前會顯示內容摘要，讓玩家確認即將加入的資料。

### GitHub 備份

玩家可以將備份保存到自己的 GitHub 私人 repository，並從已有的備份版本中選擇還原。

### Google Drive 備份

支援將備份保存到玩家自己的 Google Drive。

### 帳號與雲端文字同步

支援：

- Email 註冊與登入
- Google 帳號登入
- 手動上傳文字資料
- 手動下載文字資料
- 在不同裝置使用同一帳號

為避免資料被意外覆蓋，登入後不會自動上傳、下載或刪除本機內容。

雲端文字同步不包含：

- API Key
- 圖片
- 相簿
- 語音快取
- 其他只適合保存在裝置上的媒體資料

使用同步功能前，仍建議先建立完整備份。

## 開發與建置

安裝專案依賴：

```bash
npm install
```

啟動本機開發環境：

```bash
npm run dev
```

建立正式版本：

```bash
npm run build
```

執行完整檢查：

```bash
npm run check
```
