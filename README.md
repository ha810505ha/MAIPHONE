# MaliPhone

> 一個把 AI 角色、聊天室與手機介面結合在一起的互動專案。  
> 你可以像真的在操作一支手機一樣，和角色單聊、群聊、看錢包、改場景、管理角色設定。

## 特色

- 角色聊天室
- 群聊聊天室
- 可設定聊天室場景
- 角色卡匯入 / 匯出
- 聊天記憶與世界書
- 社群貼文與留言
- 錢包與角色錢包
- 聊天截圖與自訂關鍵字遮蔽
- Email／Google 登入與手動雲端文字同步
- 雲隱山莊與寵物小屋
- 手機式首頁與應用程式介面

## 支援的 API 供應商

| 供應商 | 說明 |
|---|---|
| OpenAI | GPT 系列 |
| DeepSeek | DeepSeek V4 Flash / Pro |
| Claude | Anthropic Claude |
| Gemini API | Google Gemini |
| Vertex AI | Google Vertex AI |
| Grok | xAI Grok |

| Ollama | 本機或代理服務 |
| NovelAI | NovelAI 模型 |
| Custom | 自訂 Base URL 與模型 |

## 主要功能

### 聊天

- 單人聊天與群聊聊天
- 聊天可切換模式
- 群聊可建立群組、編輯群組、設定成員
- 群聊支援多角色回覆
- 訊息可編輯、刪除與重試
- 可選擇手動生成回應，先連續傳送多個訊息氣泡再讓角色一起回覆
- 現實聊天可設定輸出長度
- 聊天截圖可遮蔽角色名稱、玩家名稱或自訂關鍵字

### 場景

- 每個聊天室可設定自己的場景
- 場景包含：
  - 地點
  - 小備註
- 場景只作為聊天上下文，不會改動角色本體設定

### 角色管理

- 新增角色
- 匯入角色卡
- 編輯角色設定
- 匯出角色卡
- 刪除角色聊天室

### 其他功能

- 角色記憶
- 世界書綁定
- 社群貼文
- 錢包流水
- 聯絡人與手機頁面
- 筆記、日曆、解答之書、寵物小屋與雲隱山莊
- Email／Google 帳號登入與手動雲端文字同步

## API 設定

在設定頁可以切換不同供應商與模型。  
若要使用自訂模型，也可以手動輸入模型名稱，再搭配抓取模型按鈕更新清單。

## 資料匯入 / 匯出

MaliPhone 支援：

- 全域資料備份
- 角色卡匯入 / 匯出
- 聊天室匯入 / 匯出
- GitHub 私人 repository 備份
- Google Drive 備份
- 登入帳號後手動上傳／下載雲端文字資料

雲端文字同步不包含 API Key、圖片、相簿與語音快取；這些資料仍只保留在玩家裝置上。

- 介面：手機模擬器風格

```bash
npm run dev
```
